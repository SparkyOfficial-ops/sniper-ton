# sniper-ton

Консольный бот на Rust. Он смотрит пулы STON.fi и DeDust и делает одно из двух:

- покупает жетон, когда появляется новый пул с TON;
- повторяет покупку жетона за TON с кошельков, которые вы укажете.

Слушает сеть по WebSocket TonAPI. Транзакцию подписывает библиотека `tonlib-core` из [tonlib-rs](https://github.com/ston-fi/tonlib-rs) и отправляет её в TonAPI, а если тот не принял — в TonCenter. Отдельный C++ tonlib не нужен: на Windows он долго собирается и для отправки одной транзакции ничего не даёт.

Бот не обещает прибыль. На старте пула цена двигается быстро, транзакция может прийти поздно, а жетон может оказаться пустым. Пока не проверите логи в `dry_run`, реальные TON не отправляйте.

## Что нужно

- Windows, Linux или macOS, Rust 1.80+
- бесплатный ключ TonAPI: [tonconsole.com](https://tonconsole.com)
- кошелёк v4r2 (или v3r2 / v5r1) с TON на балансе

## Запуск

```powershell
copy config.example.toml config.toml
copy .env.example .env
cargo run --release -- --config config.toml run
```

В `.env` или `config.toml`:

- `TONAPI_KEY` — ключ TonAPI
- `TON_MNEMONIC` — 24 слова. Пустая мнемоника допустима только при `dry_run = true`: бот пишет сигналы и не подписывает
- `dry_run = true` — режим репетиции

Адрес, на который класть TON:

```powershell
cargo run --release -- address
```

Проверка маршрута STON.fi без отправки:

```powershell
cargo run --release -- quote --jetton EQCxE6mUtQJKFnGfaROTKOt1lZbDiiX1kCixRv7Nw2Id_sDs --amount 0.2
```

## Режимы

`mode` в конфиге: `snipe`, `copy` или `both`.

Снайп при старте запоминает все текущие пулы и жетоны. Покупает только жетон, которого в этих списках не было. Дополнительный пул старого жетона пропускается, пока `buy_known_tokens = false`. Пул слабее `min_liquidity_ton` тоже пропускается.

Покупка на STON.fi идёт через их симуляцию: бот берёт оттуда кошелёк pTON, минимум выхода и версию роутера, затем собирает сообщение v1 или v2. Если симуляция показывает удар по цене выше `max_price_impact`, сделка отменяется.

Новый пул TON/жетон на DeDust покупается свопом в нативный vault DeDust. Минимум выхода считается по резерву пула и `slippage`.

Копирование смотрит только обмены, где кошелёк отдал TON и получил жетон. Ставка равна их входу, умноженному на `copy_scale`, но не больше `buy_amount_ton`. Покупки мельче `copy_min_ton` игнорируются. Тот же жетон не берётся повторно, пока не пройдёт `copy_cooldown_secs`.

`referral_address` — куда уходит реферальная часть STON.fi. Если пусто, в сообщении стоит ваш собственный кошелёк. Для v2 комиссия берётся из `referral_fee_bps` (не больше 100, это 1%). Для v1 размер задаёт сам пул, часто 0.1%.

`max_buys = 0` снимает лимит. Иначе процесс останавливается после стольких успешных сборок.

Остановка: Ctrl+C.
